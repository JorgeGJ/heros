# 🦸‍♂️ SuperHero Arena

Aplicación web interactiva para gestionar y enfrentar superhéroes en una arena virtual. Permite crear, editar y eliminar héroes, así como seleccionar hasta tres para competir en diversas pruebas.

## 🚀 Tecnologías Utilizadas

- [Vue 3](https://vuejs.org/) – Framework progresivo para la construcción de interfaces de usuario.
- [Vite](https://vitejs.dev/) – Herramienta de desarrollo rápida para proyectos modernos.
- [Pinia](https://pinia.vuejs.org/) – Sistema de gestión de estado para Vue.
- [Tailwind CSS](https://tailwindcss.com/) – Framework de utilidades CSS para un diseño rápido y moderno.
- [Vue Router](https://router.vuejs.org/) – Enrutador oficial para Vue.js.


## ⚙️ Instalación y Ejecución

1. **Clona el repositorio:**

   ```bash
   git clone https://github.com/tu-usuario/superhero-arena.git
   cd superhero-arena
2. **Instala dependecias:**
    npm install
    # o
    yarn install
3. **Ejecuta el proyecto:**
    npm run dev
    # o
    yarn dev
